# Tài liệu dự án (Markdown & báo cáo)

Các file `.md` hướng dẫn kỹ thuật và tài liệu báo cáo đặt tại đây.

- `*.md` — hướng dẫn setup, API, tính năng
- `BAO_CAO_USECASE_CAN_SUA.txt` — use case cần sửa trong báo cáo
- `TMDT-Final.docx` — báo cáo Word

Kết quả **testcase** nằm trong thư mục `../testcase/`.
